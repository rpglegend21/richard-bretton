# Richard Bretton — Portfolio

An interactive, game-style **campaign map** portfolio for a Technical Product Owner / Product Manager. Each project is a "level" you can open and use.

**Live:** _deploying to Vercel — link coming_

## The levels
- **The LoL Meta Market** — the 2025 pro League of Legends meta priced like a stock market, built on 2,198 real pro games.
- **Elden Ring Build Optimizer** — a deployed tool that finds the build that kills a given boss fastest (damage types, status procs, hits-to-kill).
- **Eclipse** — a solo-built action-RPG, in progress, on an AI-augmented pipeline I architected and verify by hand.

## Stack
Single static page — hand-written HTML/CSS, no build step. Type: Bricolage Grotesque · Hanken Grotesk · JetBrains Mono.

Built with AI-augmented development — directed and verified, human in the loop.
